BA KeySmith 使用说明
====================

软件名称：BA KeySmith
软件简称：BAKS
版本：v0.2.0（稳定版）
作者：HX
适用平台：Windows
适用游戏：蔚蓝档案（Blue Archive）PC 端
项目地址：https://github.com/HXwHSJS/ba-keysmith


一、软件简介
------------

BA KeySmith（简称 BAKS）是由 HX 开发的 Windows 桌面工具，用于蔚蓝档案（Blue Archive）PC 端的键位映射与自定义宏。

它可以把用户实际按下的键转换为游戏内按键输入。

例如 q -> 1，当你按下 q 键时，游戏内会收到 1 键输入。

BA KeySmith 还支持把键盘按键或鼠标按键设置为宏触发键，执行连续点击、等待、循环、组合键、鼠标拖拽等操作。


二、v0.2.0 新增功能
-------------------

- 多配置方案切换，支持新建、重命名、删除、复制配置
- 前台窗口检测，切换至其他窗口时自动停止映射输入
- 运行中编辑映射自动热更新，无需手动停止再启动
- 单 exe 独立运行，配置自动保存至用户数据目录
- 宏编辑器内置语法检查、行号、高亮和上下文补全
- 修复循环宏长按时无法停止、按键捕获穿透等多个问题


三、快速开始
------------

1. 解压 BA KeySmith 压缩包（或直接运行 BAKeySmith.exe）。

2. 以管理员身份运行 BAKeySmith.exe。
   （右键 -> 以管理员身份运行）

3. 启动蔚蓝档案 PC 端，确保游戏窗口处于前台。

4. 在 BA KeySmith 中添加映射（简单映射或宏映射）。

5. 点击"启动映射"。

6. 回到游戏中测试映射效果。


四、简单键位映射说明
--------------------

简单映射用于把一个触发键转换成另一个游戏内按键，支持两种模式：

hold（按住映射）：
  按住触发键时持续按住目标键，松开后释放。

tap（点击一次）：
  按下触发键时快速点击一次目标键，无论按多久都只触发一次。

示例：
  触发键 q、目标键 1、模式 tap -> 按下 q 时游戏内触发一次 1 键
  触发键 ctrl、目标键 1、模式 hold -> 按住 ctrl 时持续按住 1 键


五、宏脚本基础规则
------------------

1. 每条指令占一行。
2. 以 # 开头的内容为注释，不会执行。
3. 指令和参数不区分大小写，建议使用小写。
4. 参数之间用空格分隔。
5. loop 与 end 必须成对出现，支持嵌套。
6. wait 后面的时间为毫秒，支持小数。


六、常用宏指令
--------------

press <键名>              按下并按住某个键
release <键名>            释放某个键
tap <键名>                快速点击某个键
wait <毫秒>              等待指定时间
loop <次数> ... end       循环执行。loop 0 或 loop infinite 为无限循环，松开触发键自动停止
combo <键1> <键2> ...     触发组合键，如 combo ctrl c
setpos <x> <y> [mouse]   移动鼠标。加 mouse 则坐标为屏幕比例（0.0~1.0），否则为像素
setpos_rel <dx> <dy>     相对移动鼠标
drag <x> <y> [mouse] [按键]        拖拽到目标坐标
drag_rel <dx> <dy> [按键]          相对拖拽

拖拽按键支持 left、right、middle、x1、x2，也支持 mouse_left 等完整键名。


七、宏脚本示例
--------------

示例1：无限循环点击数字键 1 和鼠标左键
  loop 0
  tap 1
  tap mouse_left
  end

示例2：等待 100 毫秒后循环点击 Esc
  loop 0
  wait 100
  tap esc
  end

示例3：组合键 Ctrl+C
  combo ctrl c

示例4：移动到屏幕中心后拖拽
  setpos 0.5 0.5 mouse
  drag 800 600 left

示例5：鼠标相对拖拽
  drag_rel 120 0 left

九、配置文件说明
----------------

配置自动保存至：
  %APPDATA%\BAKeySmith\config.json

多配置方案文件：
  %APPDATA%\BAKeySmith\config_方案名.json

v0.1.0 升级至 v0.2.0 的用户首次运行时，如果 exe 同目录存在旧 config.json，会自动迁移到用户数据目录。

如需备份，直接备份上述文件即可。配置出问题时删除 config.json 后重启即可恢复默认。


十、常见问题
------------

Q: 映射或宏没有生效？
A: 确认：(1) 游戏进程 BlueArchive.exe 正在运行；(2) 游戏窗口处于前台（当前激活窗口）；(3) BA KeySmith 以管理员权限运行。

Q: 宏速度能否无限加快？
A: 已尽量降低执行延迟，实际速度受 Windows 输入调度和游戏自身处理速度限制。

Q: 鼠标右键绑定宏后，原本右键点击会不会传给游戏？
A: 通常会。BA KeySmith 可以监听鼠标按键并触发宏，但全局鼠标监听通常无法完全阻止原始点击传递给游戏。

Q: 编辑宏或捕获按键时为什么不会触发映射？
A: 打开编辑器或捕获窗口时，BA KeySmith 自动暂停映射，避免在编辑器中的输入被转换为游戏按键。

Q: 运行中编辑映射后需要重启吗？
A: 不需要。v0.2.0 支持热更新，编辑、新增、删除映射后自动生效。

Q: 压缩包里没有 config.json？
A: 正常。新版为单 exe 模式，配置文件在首次保存时自动生成到用户数据目录。
